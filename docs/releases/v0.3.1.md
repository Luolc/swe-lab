# v0.3.1 — 2026-09-03

## Oracle-guided trace synthesis, end to end

`0.3.1` closes the loop the product exists for: an unsupervised failure becomes a
guidebook, the guidebook steers a supervised rollout, and the rollout is graded —
in one command.

```sh
uv run python -m swe_lab run oracle_guided_trace <instance_id> --dataset oracle_failures
```

The chain is `oracle_analysis` → (`guidebook.md` artifact edge) → segmented
supervised rollout → unit-test grading. Both halves also still run alone
(`oracle_analysis`, `segmented_rollout_and_unit_test`).

On the first end-to-end run, the same OpenLibrary instance that scores `0` (9 of
25 required tests) unsupervised scored `1` (25 of 25) under a guidebook-guided
supervisor, which spoke once in five boundaries with a directional hint and no
answer. **That is one run on each side, not a controlled comparison** — the
unsupervised variance has not been measured, and no causal claim is made.

### Breaking

These land together because `0.3.1` is the first release carrying the native
supervision runtime and the segmented loop. If you configure supervision, read
all four.

- **`block_actor_while_judging` is an enum, not a bool.** It is now one of
  `off` / `stdout` / `sigstop`. A config passing `true` / `false` is rejected.
- **`limits.max_actor_stdout_bytes` and `limits.max_actor_stderr_bytes` are
  required.** Both are non-zero integers, and both are *terminal ceilings on the
  whole captured stream* — not backpressure. Crossing one ends the run rather
  than throttling the actor. A config written against an earlier build has
  neither field and will not load.
- **`SWE_LAB_SUPERVISOR_BASE_URL` is required** by the supervision binary.
- **Exit status is no longer the actor's fate.** Exit `1` from the wrapper means
  *not accounted for* — the supervisor cannot say what happened. Classification
  now comes from the terminal summary alone, and `supervision_metrics` takes no
  exit code at all. Anything branching on the wrapper's exit code to decide
  whether the actor succeeded is now wrong.

Smaller, still breaking:

- **`ClaudeCodeHarness` takes a `SegmentedSupervision`.**
- **`Verdict`'s unit is a rendered step, not a turn**, and it says so rather than
  converting. One turn emits several stream events, so any code reading a
  `Verdict` count as turns is off by a variable factor.
- **Credential variables are removed from the actor's environment.**

### Added

- `oracle_guided_trace`, `segmented_rollout_and_unit_test`, `segmented_rollout`,
  `oracle_analysis` workflows.
- Segmented supervision: the actor is cut every N turns, judged at the seam, and
  resumed — with a correction as the next segment's prompt, or a neutral
  continue. Four knobs are CLI-overridable:
  `--rollout.harness.segmented.{turns_per_segment,max_segments,wall_clock_seconds,max_cost_usd}`.
  Defaults are `5 / 1000 / 86400 / 1000`: deliberately large, because the
  consumer runs this at scale on its own quota. An uncontrolled run is bounded
  first by the rollout entry's 3600 s timeout.
- The in-sandbox native supervision runtime, and the host-side path that runs the
  actor under it.
- `swe_lab.datasets.oracle_failures.build` turns a failed rollout into a dataset
  row carrying its conversation, verdict and patch.
- The supervisor's provider key is adopted from the machine-wide
  `OPENROUTER_API_KEYS` when the repo-scoped name is unset.

### Known gaps

Filed, not fixed in this release:

- **`max_cost_usd` does not cap cumulative spend** (#419). The loop compares the
  *latest* segment's cost, not the running total. With the default of `1000` the
  ceiling is inert either way, but do not rely on it as a budget.
- **The `oracle_failures` builder refuses runs produced by the default
  `patch_baseline=true`** (#416). Build the Phase-A run with
  `--rollout.patch_baseline=false --unit_test.patch_baseline=false`; both halves
  must agree or the workflow's edge validation rejects it before any container
  starts.
- **Segmented cooldown is not overridable** (#415).
- Guidebook validity is *not* enforced at the seam: a missing or malformed
  guidebook is not rejected and does not fall back loudly. This is deliberate for
  this release — the gates come next, once downstream tells us which ones matter.
